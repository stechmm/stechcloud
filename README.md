# ☁️ S-Tech All-in-One Cloud & AI DevOps Suite

ဖုန်း (iOS/Android)၊ Tablet (iPad) နှင့် PC အားလုံးအတွက် **S-Tech Personal Cloud Storage**၊ ၂၄ နာရီ **Cyber Intrusion Defense Shield** နှင့် Telegram မှတစ်ဆင့် မြန်မာလို စကားပြော၍ ဆာဗာကို အစုံခိုင်းစေနိုင်မည့် **Gemini AI DevOps Brain Assistant** တို့ ပေါင်းစပ်ထားသော All-in-One System ဖြစ်ပါသည်။

## 🌟 အဓိက ပါဝင်သော စနစ်များ (Integrated Systems)

1. **☁️ S-Tech Cloud Storage:**
   - ဖိုင်၊ ဓာတ်ပုံ၊ ဗီဒီယို၊ သီချင်း၊ စာရွက်စာတမ်းများ တင်/ဒေါင်း ပြုလုပ်နိုင်ခြင်း။
   - Video / Audio Streaming၊ File Sharing၊ Recycle Bin နှင့် PWA Mobile Install စနစ်။
2. **🛡️ Cyber Defense Shield:**
   - SSH Brute-Force Hack ရန် ကြိုးစားသူများအား အလိုအလျောက် Firewall တွင် Block (Ban) ပေးခြင်း။
   - DDoS Traffic Spike စောင့်ကြည့် သတိပေးခြင်း။
3. **🤖 S-Tech AI DevOps Brain (Telegram Assistant):**
   - Google Gemini 2.0 Flash ဖြင့် ချိတ်ဆက်ထားပြီး Telegram ထဲတွင် မြန်မာလို စကားပြောသလို စာရိုက်ပို့ရုံဖြင့် ဆာဗာ ကျန်းမာရေး စစ်ဆေးခြင်း၊ Cache ရှင်းခြင်း၊ Container များ Restart ချခြင်း၊ Backup ဆွဲခြင်းများကို ဆောင်ရွက်ပေးခြင်း။
   - နေ့စဉ် မနက် ၈:၀၀ နာရီတိုင်း နေ့စဉ် အစီရင်ခံစာ (Daily Morning Report) ပို့ပေးခြင်း။

## 🚀 1-Click All-in-One Master Setup (အလွယ်ဆုံး တင်နည်း)

DigitalOcean VPS (Ubuntu 22.04 / 24.04) ထဲသို့ SSH ဝင်ရောက်ပြီး အောက်ပါ Command တစ်ကြောင်းတည်းကိုသာ Run ပေးလိုက်ပါ-

```bash
# ၁။ GitHub မှ Clone ဆွဲယူပါ
git clone https://github.com/stechmm/stechcloud.git
cd stechcloud

# ၂။ All-in-One Master Installer ကို စတင် Run ပါ
chmod +x setup-all.sh
sudo ./setup-all.sh
```

**Installer က အောက်ပါတို့ကို မေးမြန်းပေးပါမည်:**
1. Master Cloud Password (default: `admin123`)
2. Telegram Bot Token (from `@BotFather`)
3. Telegram Admin Chat ID (from `@userinfobot`)
4. Gemini AI Key (Free from `aistudio.google.com/app/apikey`)
5. Domain Name (ရှိပါက Free SSL အလိုအလျောက် ထည့်သွင်းပေးမည်)

အားလုံး ပြီးဆုံးပါက **S-Tech Cloud နှင့် AI DevOps Assistant နှစ်ခုစလုံး** တစ်ပြိုင်နက်တည်း အပြည့်အဝ စတင် အလုပ်လုပ်သွားပါမည်!
